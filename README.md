### THE DECISION RECORD

Every tool in this stack was chosen. Not defaulted to.

| Choice | Rejected Alternative | The Reasoning |
|:---|:---|:---|
| **Supabase** | Firebase | PostgreSQL is the right model for relational intelligence. RLS is a security primitive — it belongs in the database, not the application. |
| **Next.js** | CRA / Vite | API Routes + Edge Functions on one deploy surface. One codebase. Zero context switching. |
| **TypeScript** | JavaScript | Type errors are free QA. At zero budget, TypeScript is the engineer who never sleeps. |
| **Expo EAS** | Native iOS + Android split | One codebase. Two platforms. Mobile-native without splitting the team. |
| **Vercel Edge** | AWS / Render | Git-push deploys. Global edge. Zero config. Infrastructure earns nothing if you're still configuring it. |
| **Stripe** | Custom payment rails | PCI compliance as a service. Not the problem to solve pre-revenue. |
| **No Shopify** | Shopify | Full ownership is the only kind of ownership worth having. |

## ◈ HOW I THINK ABOUT BUILDING

```
──────────────────────────────────────────────────────────────────────────────

  [01]  ZERO BUDGET IS A DESIGN CONSTRAINT, NOT AN EXCUSE.
        Free-tier infra forces elegant, minimal systems. Scarcity sharpens
        architecture. Every paid service must justify its output.

  [02]  EVERY TOOL EARNS ITS PLACE.
        No tech debt from technology tourism. If it doesn't solve a real
        problem in the production stack today, it doesn't ship today.

  [03]  AI IS A FIRST-CLASS CITIZEN.
        Intelligence is designed into the data model from day one — not bolted
        on top of a schema built for manual input. If you're adding AI to an
        existing schema, you already made the wrong call.

  [04]  MOBILE-FIRST IS NON-NEGOTIABLE.
        The user is always on their phone. Desktop is the afterthought.
        Build for the context the user actually lives in.

  [05]  VERTICAL INTEGRATION IS THE MOAT.
        I own the design, the architecture, the code, and the relationship.
        Outsourcing any layer is outsourcing the moat.

  [06]  SHIP FAST. REFACTOR RUTHLESSLY.
        Velocity beats perfection until a paying customer exists. The
        prototype that closes the deal earns the right to be rebuilt properly.

  [07]  CONTEXT COMPOUNDS.
        The most valuable thing a system can accumulate is memory —
        structured, persistent context that gets smarter over time.
        That's not a feature. That's the product.

──────────────────────────────────────────────────────────────────────────────
```
