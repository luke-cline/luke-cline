I'm a **self-taught, full-stack founder** who designs the system architecture, writes production code, and closes enterprise deals. Simultaneously.

I didn't go to Stanford. I didn't raise a seed round. I don't have a CS degree.

What I have is an obsession with **building things that actually work** — and an understanding that in 2025, the only thing standing between a vision and reality is velocity.

I build companies the way SpaceX builds rockets:

> **Vertically integrated. First principles at every layer. Ruthless about what earns its place. Zero waste.**

The AI-native window is open right now. Every major sales org is still running on a CRM built in 2004. Every AI tool they've tried is either a ChatGPT wrapper or a $200/seat SaaS with a 90-day implementation timeline.

I'm building the infrastructure that replaces all of it — before the window closes.

### WHY THIS STACK — THE DECISION RECORD

Every tool in this stack was chosen. Not defaulted to.

| Choice | Rejected Alternative | The Reasoning |
|:---|:---|:---|
| **Supabase** | Firebase | PostgreSQL is the right model for relational sales intelligence. Row Level Security is a security primitive, not a layer — it belongs in the database, not the application. |
| **Next.js** | CRA / Vite | API Routes + Edge Functions collapse the backend into the same deploy surface. One codebase. One deploy. Zero context switching. |
| **TypeScript** | JavaScript | Type errors are free QA. At zero budget with no QA team, TypeScript is not optional. It's the only engineer who never sleeps. |
| **GPT-4o-mini** | GPT-4o / Claude | $0.15 per 1M input tokens. On free-tier infrastructure, cost efficiency is a constraint. The model earns its upgrade when a paying customer exists. |
| **Vercel** | AWS / Render | Git-push deploys. Global edge network. Zero config. Infrastructure earns nothing if you're still configuring it. |
| **Expo EAS** | Native iOS + Android | One codebase. Two platforms. Pre-revenue doesn't justify a native split. |
| **Stripe** | Custom payments | PCI compliance as a service. Not the problem to solve right now. |
| **No Shopify** | Shopify | Full brand ownership is the only kind of ownership worth having. |

## 📡 THE COMPETITIVE THESIS

The enterprise sales software market has a problem.

Every major CRM is **legacy infrastructure** built before LLMs existed — Salesforce, HubSpot, Outreach. They are adding AI as a feature. A button. A summarization widget. They are not rebuilding their data architecture. They cannot. The cost of migration is existential for them.

**AI-native means AI in the schema, not AI in the UI.**

| Legacy Stack | AI-Native Stack (AGNTQS) |
|:---|:---|
| CRM stores call notes manually | Whisper ASR captures every word automatically |
| Manager reviews calls manually | Deal Memory Engine surfaces patterns across all calls |
| Rep relies on memory between calls | Cold Call Copilot surfaces the right play in real-time |
| Data lives in disconnected silos | Every tool feeds every other tool |
| AI is a $30/month add-on | AI is the product |
| 90-day implementation timeline | Ships today |

The window is the **18 months before Salesforce Agentforce gets good enough that mid-market trusts it.**

That window is open right now.
